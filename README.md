# 자격증 길찾기

관심 분야나 직무로 나에게 맞는 자격증을 찾고, 따는 순서(루트)를 확인하는 사이트예요.
고등학생과 취준생을 위해 만들었어요.

## 할 수 있는 것

- 질문 3개(지금 상황, 관심 분야, 목표)에 답하면 지금 바로, 다음에, 나중에 딸 자격증을 단계별로 추천
- 첫 화면에서 고등학생 추천 자격증, 목표별 추천 루트, 자격증 처음이라면 알아둘 것 안내
- 직무나 자격증 이름으로 검색 (예: 개발자, 요리, 은행)
- 31개 관심 분야로 골라 보기
- "고등학생"을 고르면 지금 바로 응시할 수 있는 자격증만 보기
- 자격증마다 난이도, 준비 기간, 응시자격, 시험 단계, 먼저 따면 좋은 자격증과 다음 자격증 보기
- "내 루트"에 담고 단계마다 완료 표시 (이 브라우저에만 저장돼요)

## 실행

빌드 없이 `index.html`을 브라우저로 열면 돼요. `main`에 올라가면 GitHub Pages로 자동 배포돼요.

## 자격증 추가하기

`data/certs.js`의 `CERTS` 목록에 항목을 추가하세요. 각 필드 설명은 파일 맨 위에 있어요.

시험 과목, 응시자격, 일정은 해마다 바뀔 수 있어요. 접수 전에 각 시행처에서 꼭 확인하세요.
